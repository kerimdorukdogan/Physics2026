# ⚡ Problem 15 — Resistor Cube

## 📌 Given

A cube is made from 12 identical resistors.

Each edge has resistance:

R

We need to find the equivalent resistance between two opposite corners.

---

# 🔸 Step 1 — Use Symmetry

Because the cube is symmetric, some corner points have the same electric potential.

This allows the circuit to be simplified.

---

# 🔸 Step 2 — Known Result for Opposite Corners

For a resistor cube, the equivalent resistance between two opposite corners is:

R_eq = 5R / 6

---

# ✅ Final Answer

- 🔹 Equivalent resistance = 5R / 6
