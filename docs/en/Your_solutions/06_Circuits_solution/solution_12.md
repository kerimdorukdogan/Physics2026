# ⚡ Problem 12 — Transformer Currents

## 📌 Given

- 🔸 Primary turns: Np = 1000
- 🔸 Secondary turns: Ns = 200
- 🔸 Primary voltage: Vp = 120 V
- 🔸 Secondary current: Is = 3 A

We need to find:

- secondary voltage
- primary current

---

# 🔸 Step 1 — Transformer Voltage Ratio

Vp / Vs = Np / Ns

---

# 🔸 Step 2 — Find Secondary Voltage

120 / Vs = 1000 / 200

120 / Vs = 5

Vs = 120 / 5

Vs = 24 V

---

# 🔸 Step 3 — Transformer Current Ratio

Vp × Ip = Vs × Is

---

# 🔸 Step 4 — Find Primary Current

120 × Ip = 24 × 3

120 × Ip = 72

Ip = 72 / 120

Ip = 0.6 A

---

# ✅ Final Answer

- 🔹 Secondary voltage = 24 V
- 🔹 Primary current = 0.6 A
