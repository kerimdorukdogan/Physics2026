# ⚡ Problem 10 — Average Current

## 📌 Given

- 🔸 Charge: Q = 30 C
- 🔸 Time: t = 2 ms

We need to find the average current.

---

# 🔸 Step 1 — Convert Time

2 ms = 2 × 10^-3 s

2 ms = 0.002 s

---

# 🔸 Step 2 — Use Current Formula

I = Q / t

---

# 🔸 Step 3 — Substitute Values

I = 30 / 0.002

I = 15000 A

---

# ✅ Final Answer

- 🔹 Average current = 15000 A
