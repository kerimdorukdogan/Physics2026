# ⚡ Problem 3 — Propagation of Error III

## 📌 Given

- 🔸 V = (10.0 ± 0.2) V
- 🔸 I = (2.00 ± 0.05) A

We need to calculate:

- resistance
- uncertainty

---

# 🔸 Step 1 — Ohm's Law

R = V / I

---

# 🔸 Step 2 — Calculate Resistance

R = 10.0 / 2.00

R = 5 Ω

---

# 🔸 Step 3 — Relative Uncertainty

For division:

ΔR / R = (ΔV / V) + (ΔI / I)

---

## 🧮 Calculation

ΔR / R = (0.2 / 10.0) + (0.05 / 2.00)

ΔR / R = 0.02 + 0.025

ΔR / R = 0.045

ΔR = 5 × 0.045

ΔR = 0.225 Ω

---

# ✅ Final Answer

- 🔹 Resistance = 5.0 Ω
- 🔹 Uncertainty ≈ ±0.23 Ω
