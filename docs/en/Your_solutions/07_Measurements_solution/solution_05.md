# ⚡ Problem 5 — Percentage Calculation

## 📌 Given

- 🔸 t = 5.45 ± 0.22 s

We need to find the percentage uncertainty.

---

# 🔸 Step 1 — Formula

Percentage uncertainty:

(Δt / t) × 100%

---

# 🔸 Step 2 — Calculation

(0.22 / 5.45) × 100

≈ 4.04%

---

# ✅ Final Answer

- 🔹 Percentage uncertainty ≈ 4.0%
